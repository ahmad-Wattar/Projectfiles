# Academic Projects & Research Papers

This repository contains selected academic projects completed during my studies at Martin Luther University Halle-Wittenberg.

### Contents

- **Assembly and Annotation of the *Xanthomonas oryzae* TALome (August 2025)**  
  Comparative analysis of long-read, short-read, and hybrid genome assembly approaches, followed by TAL gene annotation using AnnoTALE.

- **Protein Sequence and 3D Structure Comparison (May 2024)**  
  Bachelor's thesis investigating the consistency between protein sequences and their 3D structures.

- **Software Engineering – Mill Game (February 2022)**  
  Software modeling and design of a Mill game system using UML and the MVC architecture.

### Purpose

The repository serves as a collection of my academic work and provides insights into my experience

**University:** Martin Luther University Halle-Wittenberg
